# Screen format

## The page

```
<Name>  <instrument>  <date of the data>
Result:  YES | NO | WATCH          against criteria.md as of <date>

Top three red flags
1. <flag, with the figure and its source page>
2.
3.

Reasons to buy
- <reason, with the figure and its source page>

What would change the view
- <event or figure, and its date if known>

Criteria
| Criterion | Limit | This name | Pass? | Source |

Calculations
<each ratio: formula, inputs, result>

Sources
<document, page> for every figure
```

## The Slack line

One line, at most 25 words: `<Name>: <YES|NO|WATCH>. <the main reason>. Next: <dated event>.`
